プライバシーポリシー

「有権者」が、閲覧する人の情報をどう扱うかを説明します。

アクセス解析

どのページがどれくらい読まれているかを知るために、GoatCounter（ゴートカウンター）を使っています。クッキーは使いません。

記録されるのは、見られたページのURL、参照元、ブラウザの種類、画面サイズ、国（IPアドレスから推定）などです。IPアドレスそのものは保存されず、個人を特定する情報は集めません。

GoatCounter のプライバシーポリシー：https://www.goatcounter.com/help/privacy

フォント

文字の表示に Google Fonts を読み込んでいます。そのため、ページを見るときに Google のサーバーへの接続が発生します。

Google のプライバシーポリシー：https://policies.google.com/privacy

ホスティング

このサイトは GitHub Pages で公開しています。GitHub がアクセスの記録（IPアドレスなど）を扱う場合があります。

GitHub のプライバシーに関する声明：https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement

個人情報の入力

このサイトには入力フォームはありません。名前やメールアドレスなどは集めていません。

外部リンク

出典のリンク先（政府のウェブサイトなど）での情報の扱いは、それぞれのサイトのポリシーによります。

改定

内容を変える場合は、このページでお知らせします。
